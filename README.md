# موقع شخصي احترافي + GitHub Pages

هذا المشروع مبني ليعمل كموقع شخصي سريع على GitHub Pages، مع لوحة إدارة Sveltia CMS، مشاريع، منشورات، صور، فيديو مباشر، وتكامل اختياري مجاني مع Supabase للتعليقات والتفاعلات.

## 1) تشغيل الموقع على GitHub Pages

1. أنشئ مستودعاً عاماً باسم `USERNAME.github.io`.
2. ارفع محتويات المشروع إلى فرع `main`.
3. افتح `admin/config.yml` واستبدل `USERNAME` باسم حساب GitHub.
4. فعّل GitHub Pages من Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
5. افتح `https://USERNAME.github.io`.

## 2) لوحة الإدارة

افتح `/admin/`. لوحة Sveltia تستخدم GitHub كمخزن للمحتوى. الشخص الذي يستطيع الكتابة إلى المستودع يستطيع تعديل المحتوى من اللوحة.

**لا تضع GitHub token داخل الملفات أو JavaScript.** سجّل الدخول من واجهة CMS فقط.

لإضافة أشخاص محددين: أضفهم كـ Collaborators في مستودع GitHub بصلاحيات مناسبة. إزالة صلاحية المستودع تزيل قدرتهم على الحفظ.

## 3) التعليقات والتفاعلات مجاناً

GitHub Pages لا يملك قاعدة بيانات. لذلك أضفنا تكامل Supabase اختياري.

1. أنشئ مشروعاً مجانياً في Supabase.
2. افتح SQL Editor والصق محتوى `supabase/schema.sql` وشغّله.
3. من إعدادات المشروع انسخ **Project URL** و **anon public key**.
4. ضع القيم في `assets/js/backend-config.js`:

```js
window.SITE_BACKEND = {
  url: "https://YOUR-PROJECT.supabase.co",
  anonKey: "YOUR_ANON_PUBLIC_KEY"
};
```

استخدم فقط `anon public key`. **ممنوع وضع Service Role Key في الموقع.**

التعليقات الجديدة تدخل بحالة `approved=false`، لذلك لا تظهر للناس حتى تعتمدها من لوحة/أداة إدارة قاعدة البيانات.

## 4) الفيديو

يمكنك من لوحة الإدارة وضع رابط **ملف فيديو مباشر تملكه أو لديك حق نشره**، مثل ملف MP4 مستضاف على تخزين يدعم direct URLs. سيظهر داخل مشغل HTML5 مع زر تحميل.

رابط صفحة YouTube أو TikTok ليس ملف فيديو خاماً. الموقع لا يزيل شعارات أو حقوق المواقع الأخرى ولا يتجاوز قيودها.

## 5) الصور

رفع الصور من Sveltia يضعها في `assets/uploads`. هذه الملفات عامة لأنها جزء من موقع GitHub Pages.

## 6) التشفير والخصوصية

لا يتم وضع كلمات المرور أو مفاتيح سرية داخل JSON العام. تشفير ملف عام ثم وضع مفتاح فك التشفير في نفس الموقع لا يحوّل المحتوى العام إلى سر، لأن المتصفح يحتاج المفتاح لعرضه.

إذا أردت لاحقاً **محتوى خاصاً لا يراه إلا مستخدمون محددون**، فالبنية الصحيحة هي قاعدة بيانات/تخزين خاص مع مصادقة، وليس JSON عاماً على GitHub Pages.

## 7) ما الذي يمكن تعديله من لوحة الإدارة؟

- الاسم والمسمى والنبذة والصورة وروابط التواصل.
- المشاريع وروابطها وصورها وتقنياتها.
- المنشورات والتاريخ والنشر/الإخفاء والمحتوى Markdown.
- فيديو مباشر داخل المنشور.
- معرض الصور والفيديو.

## 8) ملاحظات الإنتاج

- الموقع لا يحتاج Build step.
- يعمل مباشرة على GitHub Pages.
- التصميم متجاوب للجوال والكمبيوتر.
- يوجد Dark/Light mode.
- روابط المنشورات قابلة للمشاركة.
- يوجد escaping للمحتوى المعروض لتقليل مخاطر XSS.
- التعليقات والتفاعلات لا تعمل حتى تضبط Supabase، وتظل بقية المنظومة تعمل بشكل طبيعي.
